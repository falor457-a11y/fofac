1. github.com -> New repository (любое имя, Public) -> "uploading an existing file".
   Перетащи ВСЁ содержимое этой папки, включая папки www и .github (если Windows
   не показывает .github, включи "Показывать скрытые элементы" в проводнике).
   Commit changes.
2. Вкладка Actions -> "Build IPA" -> Run workflow. Ждать ~10 минут.
3. Открой готовый запуск -> внизу Artifacts -> fofac-ipa (zip) -> скачай, распакуй.
4. AltStore на айфоне: My Apps -> "+" -> выбери fofac.ipa.
5. При первом запуске разреши уведомления.
